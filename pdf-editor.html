How to use:
1. Choose your PDF.
2. Existing PDF text पर click करके select करें।
3. Edit Text से existing text बदलें।
4. Delete से selected text/image/QR हटाएँ।
5. + Text से नया text जोड़ें।
6. Text को drag करके move करें और corner से resize करें।
7. + Image से image जोड़ें।
8. Image को move, resize, replace या delete करें।
9. + QR से QR Code जोड़ें।
10. QR को move, resize, replace या delete करें।
11. अंत में Download PDF दबाएँ।
